# Portfolio — อินทุอร ธีรางกูร (7ess)

เว็บพอร์ตโฟลิโอส่วนตัว สายงาน **UX/UI · Front-end · Character & Game art** ใช้สมัครฝึกงานช่วงมกราคม – พฤษภาคม 2027

**เว็บจริง:** [ใส่ลิงก์หลังเปิด GitHub Pages]

## ภาพรวม

พอร์ตโฟลิโอนี้แบ่งผลงานเป็นสองสาย คือ **Build** (UX/UI, front-end, งานฮาร์ดแวร์) และ **Art** (character design, ภาพประกอบ) โดยออกแบบให้หน้าเว็บเรียบ ปล่อยให้ผลงานเป็นพระเอก

- HTML / CSS / JavaScript ล้วน ไม่ใช้ framework และไม่มีขั้น build
- โหมดสว่าง/มืด ตามการตั้งค่าเครื่อง และมีปุ่มสลับเอง
- Responsive (เดสก์ท็อป ≥ 721px, มือถือ ≤ 720px)
- เนื้อหาทั้งหมดอยู่ที่ไฟล์เดียว (`js/data.js`) เพิ่มหรือแก้ผลงานโดยไม่ต้องแตะโค้ดหน้าเว็บ
- รูปโปรไฟล์สลับหลายภาพ (รูปจริงค้างนานสุด ตามด้วยภาพวาดตัวเอง) สลับเองและกดเปลี่ยนเองได้
- Skeleton loading ระหว่างรอเนื้อหาและภาพ
- รองรับการใช้งานด้วยคีย์บอร์ด และเคารพการตั้งค่าลดการเคลื่อนไหว (`prefers-reduced-motion`)
- หน้า 404 แบบกำหนดเอง

## โครงสร้างไฟล์

```
.
├── index.html        หน้าแรก
├── build.html        หน้าผลงานสาย Build
├── build/            หน้างานแต่ละชิ้น (ไฟล์บางๆ ต่อหนึ่งงาน)
├── 404.html          หน้าไม่พบหน้า (ทำงานเดี่ยวๆ ไม่พึ่งไฟล์อื่น)
├── css/
│   └── style.css     สไตล์ทั้งหมด (สีอยู่ที่ tokens ใน :root)
├── js/
│   ├── data.js       เนื้อหาทั้งหมด: ข้อความ ลิงก์ ผลงาน ภาพ
│   ├── main.js       สร้างหน้าแรกจากข้อมูล + โหมดสว่าง/มืด + การ์ดพลิก
│   ├── build.js      สร้างหน้า Build จากข้อมูล
│   └── work.js       สร้างหน้างานแต่ละชิ้นจากข้อมูล
└── img/              ภาพผลงาน (ยังไม่ได้ใส่)
```

## รันในเครื่อง

ไม่ต้องติดตั้งอะไร เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือใช้ส่วนเสริม **Live Server** ใน VS Code (คลิกขวาที่ `index.html` → Open with Live Server) เพื่อให้หน้ารีเฟรชเองทุกครั้งที่เซฟ

ฟอนต์ Noto Sans Thai โหลดจาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์สำรองของเครื่อง

## แก้เนื้อหา

แก้ที่ `js/data.js` ที่เดียว

- **เปลี่ยนภาพ:** ใส่ path ที่ช่อง `image` เช่น `"img/profile.png"`
- **เพิ่มหรือแก้ผลงาน:** แก้รายการใน `paths[].items` (ชื่อ, บทบาท, สถานะ, ลิงก์, ภาพ)
- **ซ่อนลิงก์:** เว้นช่อง `href` เป็น `""` ลิงก์นั้นจะไม่แสดง
- **ข้อมูลที่ซ่อนไว้ใต้ปุ่ม "ดูเพิ่มเติม":** ใส่ `more: true` ที่แถวนั้นใน `about.facts`

## เผยแพร่บน GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดขึ้น repository
2. ไปที่ Settings → Pages
3. เลือก Source เป็น **Deploy from a branch** แล้วเลือกสาขา `main` และโฟลเดอร์ `/ (root)`
4. รอประมาณ 1–2 นาที เว็บจะขึ้นที่ `https://ชื่อบัญชี.github.io/` (ถ้าตั้งชื่อ repo เป็น `ชื่อบัญชี.github.io`)

หลังจากนั้นการแก้ไฟล์และ commit จะอัปเดตเว็บเองโดยอัตโนมัติ

## แนวทางดีไซน์

- **เฟรมเรียบ ให้งานเป็นพระเอก:** ใช้เทาล้วนเป็นฐาน เพื่อไม่ให้สีของหน้าเว็บแย่งสีของภาพผลงาน
- **สี accent ตัวเดียว:** ม่วงในโหมดสว่าง เหลืองในโหมดมืด ใช้เฉพาะ favicon จุดโลโก้ และปุ่มหลัก โดยหนึ่งหน้ามีปุ่มสีได้ปุ่มเดียว
- **ข้อมูลสั้นขยายในหน้าเดิม ข้อมูลลึกแยกหน้า:** หน้าแรกให้เห็นภาพรวมก่อน แล้วกดเข้าไปดูรายละเอียดทีหลัง

## สถานะ

- หน้าแรก: เสร็จ

- ภาษาอังกฤษ: วางแผนไว้ โครงสร้างข้อความแยกไว้พร้อมเพิ่มแล้ว
