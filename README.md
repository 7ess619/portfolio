เว็บพอร์ตโฟลิโอส่วนตัว สาย UX/UI + Front-end และ Character / Game art
ใช้สมัครฝึกงาน มกราคม – พฤษภาคม 2027

เปิดดูได้ที่ **https://7ess619.github.io/**
ติดต่อ: indhuon.teer@gmail.com

## เกี่ยวกับโปรเจกต์

- HTML / CSS / JavaScript ล้วน ไม่ใช้ framework และไม่มีขั้นตอน build
- ขึ้น GitHub Pages ได้ทันที (branch `main` โฟลเดอร์ root)
- เนื้อหาทั้งหมดอยู่ที่ไฟล์เดียว คือ `js/data.js` ส่วนหน้าเว็บดึงข้อมูลจากไฟล์นี้
- มีโหมดสว่าง / มืด ใช้คีย์บอร์ดได้ และเคารพการตั้งค่าลดการเคลื่อนไหว
- ข้อความหลักเป็นภาษาไทย แยกอยู่ใน `data.js` เผื่อทำภาษาอังกฤษภายหลัง

## โครงไฟล์

```
index.html            หน้าแรก
build.html            ผลงานสาย Build (UX/UI, front-end, ฮาร์ดแวร์)
art.html              ผลงานสาย Art (หน้าเดียว เลื่อนดูได้ มีแถบลิงก์ข้ามส่วน)
404.html              หน้าไม่พบ (ทำงานเดี่ยวๆ ไม่พึ่งไฟล์อื่น)
build/                หน้างาน Build 6 หน้า (หน้าบางๆ ดึงเนื้อหาจาก data.js ตาม slug)
art/                  หน้างาน Art 7 หน้า (Personal Project, Punchy, Drawing Hobby, General และตัวละคร 3 ตัว)
css/style.css         สไตล์ทั้งเว็บ (สีทั้งหมดอยู่ที่ tokens ใน :root)
js/data.js            เนื้อหาทั้งหมด (แก้ที่นี่ที่เดียว)
js/main.js            หน้าแรก
js/build.js           หน้า Build
js/work.js            หน้างาน Build
js/art.js             หน้า Art ทั้งหมด
img/                  ภาพ (ภาพ Art อยู่ที่ img/art/ เป็น WebP)
```

## แก้เนื้อหา

- ข้อความ ปี บทบาท ลิงก์ ภาพ: แก้ที่ `js/data.js`
- เพิ่มงานใหม่: เพิ่มรายการใน `data.js` แล้วคัดลอกหน้าบางๆ ใน `build/` หรือ `art/` เปลี่ยน `slug`
- ฝัง Figma prototype: ใส่ลิงก์ `/proto/` ที่ตั้งเป็น "ใครมีลิงก์ก็ดูได้" ในช่อง `figma` (เว็บแปลงเป็นลิงก์ฝังให้เอง)
- วิดีโอสาธิต: ใส่ในช่อง `videos` เป็นไฟล์ MP4 (`src`) หรือรหัส YouTube (`youtube`)
- ช่องที่ว่างหรือไม่มีภาพจะไม่แสดง จึงไม่มีกรอบเปล่าบนหน้าเว็บ

## ดูในเครื่อง

เปิดโฟลเดอร์ใน VS Code แล้วใช้ Live Server (หรือเซิร์ฟเวอร์ไฟล์นิ่งใดก็ได้)
ควรดูผ่านเซิร์ฟเวอร์ ไม่ใช่เปิดไฟล์ตรงๆ เพราะกรอบ Figma ฝังจากไฟล์ในเครื่องไม่ได้

## อัปเดตเว็บ

แก้ไฟล์ → Commit → Push เว็บบน GitHub Pages อัปเดตเองภายใน 1–2 นาที
(ถ้ายังเห็นของเก่า กด Ctrl+F5)
